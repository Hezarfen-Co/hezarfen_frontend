# Illustrations

used under the [unDraw license](https://undraw.co/license): free for personal
and commercial use, no attribution required. The license forbids redistributing
the files as a collection or using them to train AI models.

Files are kept exactly as downloaded (`https://cdn.undraw.co/illustrations/<slug>.svg`);
`src/lib/illustrations.ts` maps their stock palette onto theme tokens at load time.
